# GUPIO Employee Management System

A full-stack Employee Management System developed as an assignment for GUPIO. The application allows users to manage employee information through a simple and responsive web interface.

## Features

* Add new employees
* View employee details
* Edit employee information
* Delete employees
* Search employees
* Filter employees by department
* Dashboard with employee statistics
* Responsive and user-friendly interface

## Technologies Used

### Frontend

* React.js
* Vite
* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

### Deployment

* Frontend: Render
* Backend: Render
* Database: MongoDB
